An open energy intelligence engine for facilities, designed to analyze electricity meter data, establish historical baselines and detect unusual energy consumption patterns.

Key capabilities

  • CSV meter-data ingestion
  • Data-quality assessment
  • Historical baseline computation
  • Statistical anomaly detection
  • Deterministic evidence attached to findings
  • Incident lifecycle tracking
  • Before / after energy verification
  • Reproducible evaluation runner

Technologies

  • Python 3.11
  • FastAPI
  • SQLite
  • Statistical anomaly detection
  • REST APIs
  • pytest
  • GitHub Actions
  • Render

Accuracy note — EcoFac currently uses synthetic data. Its methods are statistical and it is not yet production-ready. No verified energy savings are claimed.
